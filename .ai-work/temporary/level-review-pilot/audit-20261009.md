# Visual-review pilot audit

Status: incomplete pilot; candidate findings only.
Reviewed: 2026-10-09.

## Findings

- The original two JSONL files each contain 1,000 unique numeric levels. This is inventory coverage, not visual-classification coverage.
- Direct image inspection is available in this session. The original agents' reported interaction limits do not establish that the images are unreadable or that the project cannot support visual review.
- Royal Match has 997 available images in numeric range 1-1,000; levels 1, 299, and 300 are absent from the manifest. Royal Kingdom has all 1,000.
- The output schemas differ: Royal Match uses string tags and `image`; Royal Kingdom uses evidence-bearing tag objects and `image_path`. A common schema is required before merging or publishing results.
- Royal Kingdom level 1's original `split_regions` candidate is contradicted by direct full-resolution inspection. The visible board is a contiguous rectangle with colored pieces above rows of boxes; a tutorial dialog obscures part of the lower board. Separate colors, obstacles, or an overlay do not establish disconnected board regions.

## Working review input

`build_contact_sheets.py` prepares 12 numbered cells per sheet, using manifest paths, explicit missing cells, original-image SHA-256 hashes, and a sheet index. All images were decoded locally with Pillow. No source image, manifest, or accepted taxonomy was changed.

- Royal Match: 84 sheets under `royal-match/sheets-20261009/`.
- Royal Kingdom: 84 sheets under `royal-kingdom/sheets-20261009/`.
- Both index files explicitly use `prepared_not_visually_reviewed`; sheet generation never marks a level reviewed.
- The first sheet of each game was rendered and inspected in this session: Royal Match levels 2-12 and Royal Kingdom levels 1-12. This establishes usable geometry-review input for 23 images, not 23 complete classifications.
- Royal Kingdom levels 1, 5, 8, 10, and 12 visibly have tutorial overlays or characters obscuring the board. Such cases require explicit occlusion flags and full-resolution inspection rather than forced geometry labels.
- Royal Match level 6 visibly contains two separated vertical regions, while Royal Match level 2 shows a continuous field with a stepped blocker boundary. These observations illustrate why board boundaries and blocker placement must be recorded separately.

Sources for these sample observations: the first numbered sheet in each game's `sheets-20261009` directory and the corresponding original images referenced by `index.json`.
