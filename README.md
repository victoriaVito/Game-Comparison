# Game Comparison

Browsable, evidence-backed archives for comparing Royal Match and Royal Kingdom level progression.

## Included archives

- `sources/royal-match-level-archive`: 13,087 Royal Match board captures, manifest, source notes, and browser.
- `royal-kingdom`: 5,300 Royal Kingdom board captures, provenance, extraction tools, review records, and browser.
- `app`: local Royal Match analysis interface.
